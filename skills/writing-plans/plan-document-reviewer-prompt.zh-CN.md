# 计划文档审查 Prompt 模板

派遣计划文档审查子代理时使用此模板。

**用途：** 验证计划分块是否完整，是否与设计文档一致，任务拆分是否合理。

**触发时机：** 每个计划分块编写完成后

```
Task tool (general-purpose):
  description: "Review plan chunk N"
  prompt: |
    你是一个计划文档审查员。验证此计划分块是否完整且已准备好用于实现。

    **待审查计划分块：** [PLAN_FILE_PATH] - 仅 Chunk N
    **参考设计文档：** [SPEC_FILE_PATH]

    ## 检查项

    | 类别 | 检查内容 |
    |------|---------|
    | 完整性 | TODO 标记、占位符、未完成的任务、缺失的步骤 |
    | 设计对齐 | 分块是否覆盖了相关的设计需求？是否存在范围蔓延？ |
    | 任务拆分 | 任务是否原子化？边界是否清晰？步骤是否可操作？ |
    | 文件结构 | 文件是否有清晰的单一职责？按职责而非层次拆分？ |
    | 文件大小 | 新建或修改的文件是否可能增长到难以整体理解的程度？ |
    | 任务语法 | 步骤是否使用 checkbox 语法（`- [ ]`）便于跟踪？ |
    | 分块大小 | 每个分块是否控制在 1000 行以内？ |

    ## 重点关注

    尤其要仔细检查：
    - 任何 TODO 标记或占位符文本
    - 标注"类似于 X"但没有实际内容的步骤
    - 不完整的任务定义
    - 缺失的验证步骤或预期输出
    - 计划承担多重职责或可能变得臃肿的文件

    ## 输出格式

    ## 计划审查 - Chunk N

    **状态：** ✅ 通过 | ❌ 存在问题

    **问题（如有）：**
    - [Task X, Step Y]：[具体问题] - [影响原因]

    **建议（仅供参考）：**
    - [不阻塞通过的改进建议]
```

**审查员返回：** 状态、问题（如有）、建议
